# US Commodity Flow Survey 2017: Power BI Dashboard

An 8 page Power BI dashboard built on the US Census Bureau Commodity Flow Survey (CFS) public use file, covering 5,983,071 shipment records.

**Author:** Eric Asiedu-Akrofi

## Download
The full Power BI project (PBIP with semantic model, report and data) is attached to the [latest release](../../releases/latest) as `Latest.zip` (128 MB). Extract it first, then open `CFS_2012_2017.pbip` in Power BI Desktop.

## Pages
1. Operations Overview
2. Mode Performance
3. Commodity & Industry
4. Network & Corridors
5. 2012 to 2017 Comparison
6. Export & Special Shipments
7. Detailed Records
8. Quality Control
